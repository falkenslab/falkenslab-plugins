# add-tool

Lista de comprobación para añadir o cambiar una herramienta en un servidor MCP de Falken's Lab hecho a partir de `falkenslab/mcp-server-template`: dónde va la lógica, cómo se escribe la herramienta (nombre, esquemas zod, anotaciones), registro, requisitos, tests y documentación.

## Instalación

Viene con el plugin `falkenslab-dev`. Añade el marketplace `falkenslab/falkenslab-plugins` e instala el plugin:

```
/plugin marketplace add falkenslab/falkenslab-plugins
/plugin install falkenslab-dev@falkenslab-plugins
```

## Uso

```
/falkenslab-dev:add-tool añade una herramienta list_courses
```
