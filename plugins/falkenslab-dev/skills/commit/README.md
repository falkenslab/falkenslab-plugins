# commit

Commits atómicos con las convenciones de Falken's Lab: Conventional Commits, mensajes en inglés, un cambio lógico por commit, añadidos por ruta y con la documentación y la verificación hechas antes. Si el repo tiene su propia skill `commit` en `.claude/skills/`, usa esa.

## Instalación

Viene con el plugin `falkenslab-dev`. Añade el marketplace `falkenslab/falkenslab-plugins` e instala el plugin:

```
/plugin marketplace add falkenslab/falkenslab-plugins
/plugin install falkenslab-dev@falkenslab-plugins
```

## Uso

```
/falkenslab-dev:commit
```
