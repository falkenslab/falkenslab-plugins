# update-docs

Mantiene la documentación al día con el código: el sitio Docusaurus de `docs/` en inglés y su traducción al español, el README, los comentarios de documentación, `.minispec/` y `CLAUDE.md`. Si el repo tiene su propia skill `update-docs`, usa esa.

## Instalación

Viene con el plugin `falkenslab-dev`. Añade el marketplace `falkenslab/falkenslab-plugins` e instala el plugin:

```
/plugin marketplace add falkenslab/falkenslab-plugins
/plugin install falkenslab-dev@falkenslab-plugins
```

## Uso

```
/falkenslab-dev:update-docs
```
